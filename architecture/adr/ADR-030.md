# ADR 030: Event Model & Sourcing

## Status
Accepted

## Context
Debugging distributed knowledge pipelines requires perfect causality tracking and event versioning.

## Decision
1. Every event on the `EventBus` must include: `event_id`, `correlation_id` (e.g., job_id), `causation_id` (parent event), and `occurred_at`.
2. Every event must include an `event_version` to support schema evolution.
3. The event lifecycle covers the full spectrum from `ConnectorConnected` to `MemoryGraphUpdated`.

## Consequences
- Guarantees idempotency.
- Enables event replay and temporal debugging.
