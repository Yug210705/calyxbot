# ADR-041: AI Extraction Interface and Confidence Scoring

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: AI Runtime

## Context
As the Calyx platform scales, we need explicit architecture to handle ai extraction interface and confidence scoring to maintain stability, scalability, and security for enterprise workloads.

## Decision
Extraction is formalized via EntityExtractor, RelationExtractor, FactExtractor stages. Confidence is separated into LLM confidence, rule confidence, merged confidence, and human verification status to build training loops.
