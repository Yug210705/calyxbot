# ADR 036: Future AI Reasoning

## Status
Accepted

## Context
The ultimate goal of Calyx is to deploy AI Employees (Agents) that operate over the Enterprise Memory Graph.

## Decision
1. The pipeline is explicitly designed to end at `GraphWriter`, populating the `Memory Graph`.
2. The AI Reasoning layer (Sprint 6) will sit on top of this graph, utilizing the `KnowledgeObject` confidence scores and `KnowledgeRelation` edges to construct context for LLM agents.
3. This separation is what defines Calyx as an enterprise memory system rather than a standard RAG tool.

## Consequences
- The data ingestion pipeline remains completely independent of the agentic reasoning execution loops.
