# ADR-043: Cost Control and Budget Abstraction

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: Platform

## Context
As the Calyx platform scales, we need explicit architecture to handle cost control and budget abstraction to maintain stability, scalability, and security for enterprise workloads.

## Decision
Introduced an Organization Budget model. All pipeline stages emit StageMetric including tokens_consumed, embedding_cost, and provider_latency to enable strict budget enforcement and billing capabilities.
