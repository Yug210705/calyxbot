# ADR 034: Connector State Management

## Status
Accepted

## Context
Connectors can fail, rate limit, or pause. The system needs to track this state independently of the active sync jobs.

## Decision
1. We will maintain a dedicated `ConnectorState` record per integration.
2. Fields include `status`, `health`, and `rate_limit_remaining`.
3. If a connector hits a rate limit, the state reflects this, and the queue pauses scheduling tasks for this organization/connector pair.

## Consequences
- Prevents cascading failures and API bans from third-party providers.
