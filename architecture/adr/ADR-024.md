# ADR 024: Pipeline SDK & Immutability

## Status
Accepted

## Context
The knowledge ingestion pipeline consists of multiple stages (Fetching, Normalizing, Chunking, Embedding, Extracting). Mutating state across stages leads to untraceable bugs.

## Decision
1. We will implement a `PipelineSDK` where every stage implements: `async def process(self, context: PipelineContext) -> PipelineContext`.
2. `PipelineContext` will be an immutable dataclass (`@dataclass(frozen=True)`). Stages must return a new instance via `context.with_embeddings(...)`.
3. The pipeline yields a `PipelineResult` containing `status`, `duration_ms`, `stage_metrics`, `errors`, and `warnings`.

## Consequences
- Trivial to debug, mock, and replay specific pipeline stages.
- Guaranteed observability at each stage boundary.
