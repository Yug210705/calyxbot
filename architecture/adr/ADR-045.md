# ADR-045: Connector Sandboxing and Validation

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: Security

## Context
As the Calyx platform scales, we need explicit architecture to handle connector sandboxing and validation to maintain stability, scalability, and security for enterprise workloads.

## Decision
Connectors execute in isolation. They must pass alidate_credentials() prior to sync. The Normalizer stage enforces strict schema validation on fetched raw data to prevent malicious payloads from reaching core processing stages.
