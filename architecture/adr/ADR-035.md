# ADR 035: API Contracts

## Status
Accepted

## Context
The frontend and external clients need a stable REST surface for managing the ingestion pipeline and inspecting data.

## Decision
1. We will freeze the following API contracts:
   - Integrations: `POST /integrations`, `DELETE /integrations/{id}`, `POST /integrations/{id}/sync`, `POST /integrations/{id}/webhook`.
   - Sync Jobs: `GET /sync-jobs`, `GET /sync-jobs/{id}`, `POST /sync-jobs/{id}/retry`.
   - Documents: `GET /documents`, `GET /documents/{id}`, `GET /documents/{id}/versions`, `GET /documents/{id}/chunks`, `POST /documents/{id}/reprocess`.
   - Knowledge: `GET /knowledge`, `GET /knowledge/{id}`.

## Consequences
- Clear contract between the platform UI and the backend services.
