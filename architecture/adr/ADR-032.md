# ADR 032: Document Versioning

## Status
Accepted

## Context
Cloud documents (Google Docs, Notion) mutate continuously. Storing only the latest version loses historical context.

## Decision
1. The `Document` model will track versioning explicitly.
2. Added fields: `parent_version_id`, `is_latest`, `change_reason`.
3. Reprocessing a document creates a new version linked to its parent.

## Consequences
- Enables point-in-time document retrieval and prevents data loss during aggressive syncs.
