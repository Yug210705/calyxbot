# ADR 027: Graph Store Abstraction

## Status
Accepted

## Context
Writing Knowledge Objects and Relations directly to a relational DB or specific graph DB tightly couples the architecture.

## Decision
1. We will create a `GraphStore` interface (`save_objects()`, `save_relations()`, `delete_document()`, `query()`).
2. The `GraphWriter` pipeline stage will depend on this interface, not a concrete implementation.
3. This allows swapping Postgres (recursive CTEs) for Neo4j or Amazon Neptune in the future without changing pipeline code.

## Consequences
- Future-proofs the most complex data layer of the application.
