# ADR-039: Pipeline and Event Versioning

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: Knowledge Engine

## Context
As the Calyx platform scales, we need explicit architecture to handle pipeline and event versioning to maintain stability, scalability, and security for enterprise workloads.

## Decision
PipelineContext and all events will carry pipeline_version and schema_version. Extractor versions (Chunker, Embedder, EntityExtractor) are stored per document. This allows deterministic reprocessing during model or schema upgrades.
