# ADR-042: Hybrid Search Strategy

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: Platform

## Context
As the Calyx platform scales, we need explicit architecture to handle hybrid search strategy to maintain stability, scalability, and security for enterprise workloads.

## Decision
Enterprise search will not rely solely on vector embeddings. It will use a hybrid strategy combining pgvector (semantic), GraphStore (relationships), and PostgreSQL Full Text Search (keywords), weighted dynamically based on the query intent.
