# ADR-040: Identity Resolution Strategy (Knowledge Graph)

**Date**: 2026-07-02
**Status**: Accepted
**Domain**: AI Runtime

## Context
As the Calyx platform scales, we need explicit architecture to handle identity resolution strategy (knowledge graph) to maintain stability, scalability, and security for enterprise workloads.

## Decision
KnowledgeObjects will be resolved using a multi-step deterministic matching pipeline (Exact Match -> Rule-based Canonicalization -> LLM Disambiguation). Unique constraint enforced on (organization_id, canonical_key) to prevent graph explosion.
