# ADR 033: Search Architecture

## Status
Accepted

## Context
The primary interaction with the system is search and reasoning. We need to reserve the API surface for future agentic capabilities.

## Decision
1. We will reserve `POST /api/v1/search`, `POST /api/v1/ask`, and `POST /api/v1/reason`.
2. These endpoints will orchestrate Hybrid Search (Keyword + Vector) and Graph Traversal.
3. They are decoupled from the knowledge ingestion APIs.

## Consequences
- API clients can depend on a stable URL structure for the search experience.
