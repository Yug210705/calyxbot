# ADR 025: Document Model

## Status
Accepted

## Context
Documents are the primary artifact fetched from connectors, but they are not the source of truth for the Enterprise Memory Graph.

## Decision
1. The `Document` model acts as a staging representation.
2. It will contain `metadata` as a JSONB column to prevent schema drift across providers.
3. It will track checksums and mime types.
4. `DocumentChunk` will map directly to the parent document and store chunk-specific metadata and token counts.

## Consequences
- Clean separation between source data and extracted knowledge.
