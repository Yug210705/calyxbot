# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-01

### Added
- Automated Render deployment configuration (`render.yaml`).
- Transaction pooling configuration for production Supabase connectivity (`DATABASE_URL`).
- `pyjwt[crypto]` backend dependency to correctly verify ES256 asymmetric JWTs generated by modern Supabase Auth.
- Cross-worker isolation in Playwright `auth-flow.spec.ts` using randomized test user emails.

### Changed
- Replaced the local SQLite database with a production-ready Supabase PostgreSQL instance.
- Configured FastAPI `NullPool` in SQLAlchemy connection setup for optimized behavior behind the Supabase transaction pooler.
- Environment configurations for E2E tests have been mapped to actual production domains (`calyx-backend.onrender.com` & `calyxbot.vercel.app`).
